GitHub Actions External Scheduler

0 workflows

How it works
Add a commented # @external-schedule: block to any workflow file. Supported fields are enabled, timezone, ref, inputs, and schedule items with cron. Per-schedule inputs override top-level inputs. 
# @external-schedule:
#   enabled: true
#   timezone: "Europe/Stockholm"
#   ref: "main"
#   inputs:
#     environment: "staging"
#     message: "Scheduled run"
#   schedule:
#     - cron: "0 12 * * *"
#     - cron: "0 18 * * 1-5"
#       inputs:
#         environment: "production"
